Quick Help
What is Shodan?

Shodan is a search engine for internet-connected devices. It scans the internet and catalogs information about servers, IoT devices, and other connected systems.

Getting an API Key
  1. Visit account.shodan.io
  2. Create a free account or sign in
  3. Your API key will be available on the account page
  4. Free accounts have limited query credits
Query Tips
  • IP lookup: 192.168.1.1
  • Service search: Apache 2.4
  • Port search: port:22
  • Country filter: country:US
