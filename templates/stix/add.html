Format Requirements
Single STIX Object:
  • Must be valid STIX 2.1 JSON format
  • Must include required fields: type, id, created, modified
  • Supported object types: indicator, malware, threat-actor, campaign, attack-pattern, vulnerability, report, etc.
  • Can include relationships, external references, and custom properties
  • Timestamps must be in ISO 8601 format (UTC)
STIX Bundle:
  • Must have "type": "bundle"
  • Must contain "objects" array with STIX objects
  • Can contain "relationships" array to link objects
  • All objects and relationships will be imported automatically
  • Objects are deduplicated if they already exist
Example
{
  "type": "malware",
  "id": "malware--12345678-1234-1234-1234-123456789012",
  "created": "2024-01-10T12:00:00.000Z",
  "modified": "2024-01-10T12:00:00.000Z",
  "name": "Example Malware",
  "description": "A test malware object",
  "malware_types": ["trojan"],
  "labels": ["malicious-code"]
}
